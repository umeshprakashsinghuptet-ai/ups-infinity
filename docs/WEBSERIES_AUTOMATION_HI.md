# Web Series Studio — Automation विवरण

## उपलब्ध मोड
- AUTO MODE: curated local topic bank से शीर्षक, विषय, genre, audience, episode count, duration और language भरता है।
- MANUAL MODE: उपयोगकर्ता हर field संपादित करता है।
- HYBRID MODE: उपयोगकर्ता कुछ fields देता है; AUTO-FILL बाकी खाली fields भरता है।

## बटन
- सब कुछ AUTO-FILL करें: सभी fields को चुने हुए topic preset से भरता है।
- नया विषय सुझाएँ: topic bank से दूसरा preset चुनता है।
- फ़ॉर्म साफ़ करें: केवल Web Series form/output साफ़ करता है।
- सीरीज प्लान बनाएँ: Series Bible, continuity rules और episode-wise beats बनाता है।
- ग्रीन कॉपी / JSON डाउनलोड / TXT डाउनलोड: बने प्लान को export करता है।
- एपिसोड स्क्रिप्ट ड्राफ्ट: episode-wise script outline TXT देता है।

## सीमाएँ
यह frontend-local planner है। Topic suggestions curated/offline हैं, live Google Trends या web research नहीं। वास्तविक तथ्य-जाँच, विस्तृत dialogue/script generation, image/video/audio generation, lip-sync और rendering के लिए secured backend provider integration और end-to-end testing आवश्यक है।
