## Production Director Engine (new in this build)
- Local scene-wise production plan: duration, 10–12 scenes, objective, image/video prompts, dialogue placeholder, audio direction, transitions and continuity notes.
- Local six-track timeline plan and export validation checklist.
- JSON and TXT export; project-local save.
- AUTO / MANUAL / HYBRID mode value is retained in the plan.
- Explicit boundary: this creates a production plan, not rendered image/video/audio.
